# Vini Berger Portfolio

Personal developer portfolio built with Next.js 15, React 19, Tailwind CSS 4, and React Icons.

## Local development

```bash
npm ci
npm run dev
```

## Quality checks

```bash
npm run ci
```

The CI command runs ESLint, the lightweight Node test suite, and a full production build.

## Continuous integration

GitHub Actions runs the same checks on pull requests and on every push. This means changes are validated before/alongside the deployment flow connected to the repository.
